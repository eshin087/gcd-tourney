# Sasuke jumpSquat v07 diagnostic atlas

This directory contains a diagnostic-only 48-color pack of the single-frame Sasuke `jumpSquat_v07` candidate. It is provided for Astra's visual inspection and is not a production atlas or an art approval.

The source is `art/characters/sasuke/raw/jumpSquat_v07.png`, generated by call `exec-d006ed27-5a55-43b4-98a7-25c633e8ec02` and recovered from the exact `item_completed` event recorded in `art/characters/sasuke/production/round4/candidate-inventory.json`. Candidate SHA256: `8b8cb826e0d4105e5bc66dc1bd25e6c6e8399b1d7b8930f778b35428ed3ad1bb`.

`art/characters/sasuke/raw/jumpSquat_v07.json` is a byte-identical copy of the v06 calibration sidecar (SHA256 `479caef8366ee22fe038e4f9cc34c41f075a7fff87da727ddb12a8f74d36e96`). It preserves Claude's exact prior values, including bodyHeight 157; the v06 source sidecar is unchanged. Without this version-specific companion, the packer uses manifest bodyHeight 162.

The standard auto-gate dry run after adding the byte-identical sidecar used bodyHeight 157 and failed because the v06 `scaleManualQA` does not certify v07 and the crouched pose is low confidence. The report is `standard-pack-report.json` (exit code 1); it says jumpSquat is `unmeasured` (head 0.985, feet 0.829), `strict: true`, and nothing was written. An earlier attempt before the sidecar existed used manifest bodyHeight 162 and also wrote nothing.

For visual inspection only, `manifest.json` here is cloned from production manifest SHA256 `007bc4eb7bf9efda2dc99de563d61db50ad88eaab572558fb4945a815632cfd1` and changes only `characters.sasuke.scaleGate` to `warn`. This allows the diagnostic atlas to be written while preserving the scale audit findings. Production `art/manifest.json` remains on its normal gate and retains v03 approval plus v06-only manual QA.
