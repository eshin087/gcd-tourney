What to judge

The height relationship is the focus: near-equal teens, slightly shorter Killua, tall lean Gojo. These new standing drawings are candidates; the earlier combat drawings are preserved separately and have not yet been calibrated to this study.

My recommendation

Use this common height scale as the reference for the next combat-sample pass. Keep the lean builds and individual head designs. Full animation redraw is now authorized and in progress. New strips will return for review.

Measurements and limits

Target body heights excluding hair: Naruto 200px, Sasuke 202.41px, Killua 190.36px, Gojo 228.92px. Gojo's published height is over 190cm; 190 is a conservative working value, not an exact canon measurement. There is no official crossover scale: this study uses the same centimetre scale across series.

Skull crowns are inferred under hair with approximately ±2px uncertainty at review size. Shoe soles and minor perspective also limit precision. All four packed references use 48 colours with no clipping. They are static references, not production animation scale-gate passes.
